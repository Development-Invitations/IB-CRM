# IB CRM

Корпоративная CRM для **IB OOO "ISHONCHLI BOSH BUXGALTER"**.
Текущая версия: **v0.1.0** (offline-прототип, без подключения к серверу).
Desktop-ядро: **Tauri** (Rust) — лёгкая и современная альтернатива Electron.

Полное ТЗ и журнал разработки — в [`docs/TZ.md`](docs/TZ.md). Перед новым чатом с Claude
по этому проекту прикрепляй актуальный `docs/TZ.md`, чтобы не терять контекст между сессиями.

## Стек

- Tauri 2 (Rust) + React + TypeScript (Vite) — фронтенд общается с ядром через `invoke`
- SQLite (rusqlite) — локальное хранилище для offline-режима v0.1.0
- В плановой версии: NestJS + PostgreSQL на сервере (см. `docs/db/schema.sql`)

## Предварительные требования

Так как ядро на Rust, помимо Node.js понадобится:

1. **Rust** — https://www.rust-lang.org/tools/install (rustup)
2. **Tauri зависимости для Windows** — Microsoft C++ Build Tools + WebView2
   (WebView2 обычно уже стоит в Windows 10/11; остальное ставит `rustup`/установщик Tauri —
   см. https://v2.tauri.app/start/prerequisites/)

## Установка и запуск

```bash
npm install
npm run tauri:dev
```

Откроется окно приложения. При первом запуске нужно будет создать администратора
(логин + пароль, без подтверждения почты) — учётка сохранится в локальном SQLite-файле
`ib-crm.db` (в стандартной app-data папке пользователя).

## Генерация иконки приложения из лого

Исходник лежит в `src-tauri/icons-source/logo.png` (1024×1024, прозрачный фон).
Полный набор иконок под все платформы генерируется одной командой:

```bash
npm run tauri:icon
```

Она разложит иконки по `src-tauri/icons/` — как раз туда, куда ссылается `tauri.conf.json`.

## Сборка установщика (позже, когда понадобится)

```bash

```

## Что уже работает в v0.1.0

- Первый запуск → создание администратора (локально, офлайн)
- Вход по логину/паролю
- Каркас интерфейса: сайдбар с будущими модулями ("скоро"), переключение темы (тёмная/светлая)

## Чего нет пока
